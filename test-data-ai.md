# Test 3: Data / AI validation test

**Objective:** Verify that the TF-IDF matching engine ranks the true
corresponding found item as the top-1 suggestion for lost items that have
a real counterpart, and does not confidently suggest a match for lost
items that have none.

**Setup:** Local machine (no AWS dependency). Python 3, pandas,
scikit-learn. Synthetic dataset generated by data/generate_dataset.py
(fixed random seed 42, reproducible): 105 lost item reports, 105 found
item reports, across 8 item categories (Bottle, Keys, Card, Bag,
Umbrella, Earphones, Jacket, Watch). 85 lost items have a true
corresponding found item; 20 do not (ground truth in
data/ground_truth.csv).

**Command:**
```
python3 data/generate_dataset.py   # regenerate data (optional, already committed)
python3 analytics/match.py
```

**Expected result:** High precision@1 on the 85 items with a true match,
and a low false-positive rate on the 20 items with no true match, using a
similarity threshold of 0.30 to suppress low-confidence suggestions.

**Actual result:**
- Precision@1 on items with a true match: **32.9%** (28/85 correct)
- False positive rate on items with no true match: **100%** (20/20
  incorrectly given a suggestion above the threshold)
- A threshold sweep (0.30 to 0.70) was run; no threshold value achieves
  both good precision and a low false-positive rate simultaneously,
  because the similarity score distributions for matched and unmatched
  items overlap substantially (matched median 0.68, unmatched median
  0.54, see evidence/test-data-ai-output.csv).

**Root cause (from manual inspection of misclassified pairs):** the
dataset uses 8 item categories with a small, fixed set of phrasings per
category. Two *different* items of the same category (e.g. two different
black umbrellas lost by two different students) produce text nearly as
similar as a *true* lost/found pair, because "category + generic
adjectives" dominates the TF-IDF vector. Example: lost item "black
folding umbrella" was matched to an unrelated found "black folding
umbrella" (score 0.777) instead of its true counterpart, which used
different wording (score for the true match was lower).

**This is reported as a genuine finding, not adjusted after the fact.**
An earlier version of this test used only 4 hand-picked, deliberately
distinct rows and reported 100% precision — that result was an artefact
of the tiny, non-representative sample and has been discarded in favour
of this larger, more honest evaluation.

**Improvement plan:** (1) add a secondary matching signal beyond text,
e.g. date proximity and location match as weighted features alongside
the TF-IDF score, since two independent black umbrellas are unlikely to
be found at the same location on the same day; (2) consider requiring
the reporter to add one distinguishing detail (a scratch, a sticker, a
serial number) that TF-IDF can pick up on; (3) surface the top-3
suggestions to Security staff for manual confirmation rather than
auto-resolving on top-1, since the tool is a triage aid, not an
automated decision-maker (see W4/W5 in Section 4 of the report).
