# AI Use Declaration

**Project:** Campus Lost & Found, INF2006 Team 10

This declaration follows the module's academic integrity policy. All AI-assisted output was reviewed, modified where needed, and verified by the team before inclusion. No AI-generated content is presented as unverified fact.

## 1. AI tools used

Claude (Anthropic) was the only AI tool used in this project. No other AI tools, such as ChatGPT or GitHub Copilot, were used.

| Tool | Provider | Used by |
|---|---|---|
| Claude | Anthropic | Team 10 members |

## 2. Where AI was used

| Area / File | How AI was used | Team modification |
|---|---|---|
| Flask application | Suggested route structure and form input-validation patterns | Designed the lost/found reporting and claim workflow; added claim verification using `private_detail` and `verification_answer` columns; added password security |
| TF-IDF matching (`analytics/`) | Explained the TF-IDF and cosine similarity approach for comparing text | Chose to match items by text description instead of images; defined preprocessing, the match-percentage output and the evaluation approach |
| AWS setup | Helped troubleshoot console steps (e.g. locating RDS database creation in the updated console, EC2 public IPv4 settings) | All AWS resources were configured and verified by the team in the AWS console, following INF2006 lab materials |
| Security | Suggested threat categories to consider for the threat-control map | Mapped threats to controls actually implemented in the project and tested them |
| Documentation | Provided templates for `TEAM_CONTRIBUTIONS.md` and `AI_USE_DECLARATION.md`, and suggested a role split | Assigned roles, filled in all content and checked it against the project artefacts |
| `report.pdf` | Grammar and clarity suggestions | Analysis, results and conclusions written by the team |

## 4. Verification performed

- **Code:** all AI-suggested code was read, understood and tested by the member responsible before merging; the functional workflow is verified in `evidence/test-functional.md`.
