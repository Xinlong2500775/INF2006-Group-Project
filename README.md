# Analytics: TF-IDF Matching Engine

## How to run
```
pip install pandas scikit-learn
python3 data/generate_dataset.py   # regenerates data/*.csv (fixed seed, optional)
python3 analytics/match.py
```
No AWS account or credentials required. Runs fully offline.

## What it does
Reads the synthetic dataset from ../data/lost_items.csv and
../data/found_items.csv (105 rows each; see ../data/DATA_DICTIONARY.md
for field definitions and provenance), combines each report's
category/description/location into one text field, fits a shared TF-IDF
vectoriser across both sets, and scores every lost-found pair with cosine
similarity. Applies a 0.30 similarity threshold so low-confidence pairs
are reported as "no suggestion" rather than a forced guess.

## Output
Printed to console and saved to ../evidence/test-data-ai-output.csv.
Evaluated against ../data/ground_truth.csv (85 true matches, 20 lost
items with no true match). See ../evidence/test-data-ai.md for the full
result, including an honest discussion of why precision is lower than an
initial 4-row pilot suggested, and the planned improvements.

## Dataset provenance
Synthetic data generated by data/generate_dataset.py with a fixed random
seed (42) for reproducibility. No real user data was used.

## Reproducible command
python3 analytics/match.py
